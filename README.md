# coding-practice

A repository for coding practice

## Language

- JavaScript (Node.js)

## Directory Structure

| Directory                                        | Description                                   |
| ------------------------------------------------ | --------------------------------------------- |
| `atcoder/`                                       | Solutions to AtCoder problems                 |
| `atcoder/abs/`                                   | AtCoder Beginners Selection (ABS)             |
| `dsa/`                                           | Basic data structures and algorithms practice |
| `method/`                                        | JavaScript method references                  |
| `paiza-levelup/`                                 | Solutions to Paiza level-up problems          |
| `paiza-levelup/algorithms/`                      | Standard algorithm menus                      |
| `paiza-levelup/algorithms/bfs-dfs/`              | BFS and DFS problems                          |
| `paiza-levelup/algorithms/binary-search/`        | Binary search problems                        |
| `paiza-levelup/algorithms/euclidean-algorithm/`  | Euclidean algorithm problems                  |
| `paiza-levelup/algorithms/linear-search/`        | Linear search problems                        |
| `paiza-levelup/algorithms/prefix-sum/`           | Prefix sum problems                           |
| `paiza-levelup/algorithms/prime-number/`         | Prime number problems                         |
| `paiza-levelup/algorithms/stack-queue/`          | Stack and queue problems                      |
| `paiza-levelup/b-rank/`                          | Problems for reaching B rank                  |
| `paiza-levelup/b-rank/dp/`                       | Dynamic programming problems                  |
| `paiza-levelup/c-rank/`                          | Problems for reaching C rank                  |
| `paiza-levelup/c-rank/stdout/`                   | Standard output problems                      |
| `paiza-levelup/d-rank/`                          | Problems for reaching D rank                  |
| `paiza-levelup/d-rank/cd-rank-input-template/`   | C and D rank standard input template problems |
| `paiza-levelup/d-rank/d-rank-skillcheck-sample/` | D rank skill check sample problems            |
| `paiza-levelup/d-rank/d-rank-test-1/`            | D rank proficiency test problems (set 1)      |
| `paiza-levelup/d-rank/d-rank-test-2/`            | D rank proficiency test problems (set 2)      |

`script.js` is a scratch file for solving problems.
